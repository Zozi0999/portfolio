Website portofolio digital interaktif dan modern yang menampilkan profil profesional, keahlian teknis, showcase proyek kecerdasan buatan, serta brankas kredensial sertifikasi resmi dari Microsoft Elevate, Dicoding Indonesia, BISA AI Academy, dan Technology Channel.

---

## 🌟 Fitur Utama

1. **Credentials & Certification Vault**:
   - Menampilkan 5 sertifikat terverifikasi (Microsoft Elevate, Dicoding, BISA AI, Technology Channel).
   - Thumbnail resolusi tinggi (HD) dengan efek modal preview / lightbox.
   - Tombol langsung untuk **Membuka PDF Asli** dan **Mengunduh Sertifikat**.
   - Filter interaktif berbasis kategori (*Artificial Intelligence*, *Data Science*, *Python*).

2. **Interactive UI & Visuals**:
   - Dynamic Interactive Constellation / Particle Background (Canvas HTML5).
   - Typed Subheader Effect dinamis.
   - Glassmorphism & Cyber-Modern Aesthetic (Tailwind CSS, Font Awesome 6).
   - Desain sepenuhnya responsif (Mobile, Tablet, Desktop).

3. **Sections Lengkap**:
   - **Hero Section**: Bio singkat, status badge ketersediaan, dynamic typing, dan statistik ringkas.
   - **About Me**: Filosofi, pilar keahlian, dan informasi detail.
   - **Skills & Tech Stack**: AI & ML, Python Engineering, Data Science, serta ekosistem tools.
   - **Projects Showcase**: Mockup proyek AI End-to-End, Deep Vision, dan Document Intelligence.
   - **Milestones & Roadmap**: Timeline pencapaian sertifikasi tahun 2026.
   - **Contact & Connect**: Form pesan interaktif dan tautan media sosial.

## 🚀 Cara Menjalankan Portofolio

### Cara 1: Langsung Buka di Browser (Offline Ready)
Cukup klik ganda (double-click) pada file `index.html` atau buka melalui browser apa pun (Google Chrome, Microsoft Edge, Firefox, Brave).

### Cara 2: Menjalankan Local Web Server (Python)
Jalankan perintah berikut di PowerShell atau Terminal:

```pwsh
cd C:\Users\user\digital-portfolio
python -m http.server 8000
```
Kemudian buka browser di `http://localhost:8000`.
